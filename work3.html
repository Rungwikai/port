Ex3: HTML : สร้างหน้าเว็บส่วนตัวอย่างง่ายด้วย HTML

Level: Beginner

โจทย์

  • สร้างหัวข้อหลักของหน้าเว็บ (เช่น ชื่อของคุณ) โดยใช้แท็ก <h1>
  • สร้างย่อหน้าแนะนำตัวเองสั้นๆ โดยใช้แท็ก <p>
  • เพิ่มลิงก์ไปยังเว็บไซต์ภายนอกที่คุณชื่นชอบ (เช่น Google, Facebook) โดยใช้แท็ก <a>
  • เพิ่มรูปภาพลงในหน้าเว็บ โดยใช้แท็ก <img> (สามารถใช้รูปภาพ Placeholder ได้ เช่น "https://via.placeholder.com/150")
  • ตรวจสอบให้แน่ใจว่าแท็ก HTML ทั้งหมดถูกปิดอย่างถูกต้อง
